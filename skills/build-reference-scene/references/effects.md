# 特效与难复刻外观

按目标选表现方式，再决定资源和工具；不要求每种效果都用网格建模。

| 对象 | 近景/离线选择 | 实时选择与检查 |
|---|---|---|
| 火焰、烟雾 | 合适VDB缓存或燃烧模拟 | 有许可的flipbook/粒子/引擎VFX；透明混合、深度与性能 |
| 水与液体 | 合适模拟/几何与透射材质 | 水面shader/法线动画/局部粒子；反射和交互 |
| 布料、绳索 | 现成扫描/网格或布料模拟 | 简化网格、骨骼/顶点动画；穿插和性能 |
| 植物、毛发 | 适合的扫描资产、曲线或毛发系统 | LOD、卡片/实例；轮廓、透明排序和过度绘制 |
| 岩石、雕塑、旧木器 | 扫描模型、优质模型与PBR | 重拓扑/烘焙；轮廓与纹理密度 |

## 火焰验收
写实近景不要用几个实心发光椭球交差。评估VDB单帧或模拟帧，检查真实grid名称、温度单位、烟密度与发射属性，不能把0–1数值直接当Kelvin。先看内部明暗、分叉/断裂轮廓与基部，再调环境照明及克制辉光。柴火需有焦化、炭火或灰烬依据，不能靠白色亮团遮盖。

动画增加帧率、连续性、循环与缓存路径检查；静帧只需合适帧。VDB通常是外部文件，需相对路径并随允许分发的依赖交付；GLB一般不能直接保存Cycles体积与合成器。改用实时方案必须在目标引擎实测。

JangaFX免费VDB页面可作为候选入口；具体下载、许可和尺寸每次核对。下载失败时记录失败，不能在交付中说已换成真实体积。风格化网格效果可以采用，但应明确表现类型。
