# 专项模块路由

以下是独立整理的方法摘要，覆盖此前提及的工作流方向。并未安装同名上游技能或执行脚本；需要具体实现时查原作者文档并审查所用文件，工具仍以当前环境提供的能力为准。

| 方向 | 启用条件 | 生产与验收 |
|---|---|---|
| Curio mechanism | 古董器械、齿轮、铰链 | 先BOM/尺寸/轴/接口，再可运动体块与细节；浅雕用贴图，活动部件真实分离；请求运动时实际验证 |
| mesh-split-fill | 已有模型需拆件/封口 | 原件只读，定义部件和接缝，最难接缝试产；保留设计孔洞，封口方向正确，导出重导入检查 |
| Curio oil paintings | 油画画芯与笔触 | 底色与形体/笔触法线配准；实际艺术图不能被任务JSON或噪声纹理替代；真伪画配对仅在请求时制作 |
| Curio frame | 画框、徽章与尺寸变化 | 画芯/框/背板独立；按画幅重建框条、UV物理密度稳定，徽章不拉伸；正面及斜视检查 |
| Curio jewelry | 珠宝、宝石、玻璃饰品 | 闭合厚度、真实刻面、硬法线与镶口配合；透明alpha不等于透射，换背景验证透射表现 |
| Noir character | 2.5D可重打光角色 | 对齐底色/alpha/形体法线，左右光及normal开关对照；保留用户风格，不自动变成动物黑色电影风；不是绑定3D角色 |
| Curio part finishing | 游戏内打磨修复交互 | 连续接触去料、过切与失败、合格件及安装；实际游戏测试；静态任务不添加游戏系统 |
| Evolve assets | 参数资产/版本/引擎级质量 | 明确质量契约，源与报告hash对应、GLB重导入、参数探测；真实引擎证据；执行命令不等于审批 |
| Meshy generation | 复杂独立形体生成或贴图 | 使用当前已安装Meshy技能；复用认证、估价、任务ID和异步状态；不盲目重提交 |
| Blender lighting | 场景打光 | 以尺度和参考光向决定主/补/轮廓/环境光，区分材质响应；不照搬固定功率 |
| Blender rendering | 输出图像/动画 | 依据目标选引擎，实际检测设备/版本、相机/尺寸/降噪/色彩；动画优先可恢复帧序列 |
| Reference look calibration | 参考图外观匹配 | 先几何、UV与相机，再比较主体范围、色相、亮度与发光；区域指标辅助看图，不替代看图 |
| Authored render workflow | 既有blend输出 | 保留作者相机、灯光、材质、世界及合成器；记录缺依赖和实际设置；干净进程重现 |
| bpy quality workflow | 程序化建模/可维护场景 | 设计→搭建→视觉评审；组件清单、方向/比例、接地和实例复用；代码分组件，不改无关物件 |

流程按需组合，不强制每个任务跑全部方向。原作者项目见仓库SOURCES.md，参考文件不能替代对应工具的安装或实测。
