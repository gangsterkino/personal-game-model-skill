# Personal Game Model Skill

个人三维场景制作工作流：参考图分析 → 资产清单 → 现成资产检索/建模/生成 → 材质与场景组装 → 灯光渲染 → 视觉检查 → 可编辑工程交付。

## 使用

将 `skills/build-reference-scene/` 整个目录安装到支持 Agent Skills 的客户端技能目录，然后调用 `$build-reference-scene`，提供参考图或现有 `.blend` 和目标效果。具体安装方式以客户端文档为准。

示例：

> 用 build-reference-scene 根据参考图制作完整酒馆场景。难复刻的物件优先查找许可合适的现成模型、扫描材质或特效并直接复用。先试渲染，检查真实画面后继续完善，交付可编辑工程和最终图。
